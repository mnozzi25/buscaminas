# Buscaminas

Trabajo práctico final de la materia **Desarrollo y Arquitecturas Web** - Ingeniería en Sistemas - UAI.

## Descripción

Versión web del clásico juego Buscaminas, desarrollada con HTML5, CSS3 y JavaScript (ES5).

## Cómo jugar

- Clic izquierdo: revelar una celda.
- Clic derecho: colocar o quitar una bandera.
- Carita o barra espaciadora: reiniciar la partida.

## Tecnologías

- HTML5
- CSS3 (Flexbox)
- JavaScript (ES5)
